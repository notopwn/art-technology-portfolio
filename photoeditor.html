PhotoEditor

마음껏 고치고.
다시 바꿀 수 있도록.

원본은 남겨 두고, 편집은 계속 이어 간다.
레이어·선택·시간축을 한 문서에 연결한 이미지 편집기.

비파괴 편집프레임·GIFmacOS 네이티브

이미지를 불러오기 전의 실제 앱 화면 · 중앙 캔버스 / 왼쪽 도구 / 오른쪽 레이어와 속성

WHY I BUILT IT

도구를 더할 때마다,
작업을 다시 시작하지 않게.

처음에는 macOS 이미지 편집기를 직접 만들어 보고 싶었다. 레이어와 브러시에 효과와 GIF 편집까지 더하다 보니, 기능이 많아지는 것보다 중요한 게 생겼다. 도구를 바꿔도 앞에서 한 작업을 그대로 이어 갈 수 있어야 했다.

01 / LAYERS

원본과 편집을 따로.

원본 자산과 조정값을 구분해 보존한다. 레이어와 마스크, 효과를 조합하고 결과를 다시 조정할 수 있게 했다.

02 / SELECTION

선택도 다시 쓸 수 있게.

색이나 객체로 만든 선택을 마스크와 알파 채널로 남긴다. 잠깐 그은 윤곽이 다음 편집에서도 쓸 수 있는 자료가 된다.

03 / ANIMATION

한 장에서 여러 프레임으로.

같은 레이어 기반에서 프레임과 시간을 다룬다. 정지 이미지 편집을 GIF의 재생과 내보내기까지 연결했다.

ONE DOCUMENT, MANY EDITS

결과뿐 아니라,
고친 방식까지.

이미지를 합쳐 저장하면 조정할 여지가 사라진다. 그래서 편집 가능한 프로젝트와 전달할 이미지를 구분했다. 프로젝트에는 레이어·선택·효과·프레임과 참조 자산이 함께 남는다.

새 도구도 같은 문서와 실행 취소 체계를 사용한다. 저장한 프로젝트를 다시 열어 편집을 이어 갈 수 있다.

MAKING IT FEEL RIGHT

직접 써 보니,
작은 조작이 걸렸다.

이미지를 추가했는데 바로 옮길 수 없거나, 프레임을 놓을 위치가 불분명하면 편집 흐름이 끊겼다. 실제로 쓰면서 느낀 불편을 코딩 에이전트에게 전달하고, 결과를 다시 확인하며 다듬었다.

01

추가한 다음, 바로 이동하기.

새 이미지와 텍스트를 만든 직후 다음 조작으로 자연스럽게 이어지도록 도구와 작업 상태를 점검했다.

02

프레임을 어디에 놓을지 보이게.

GIF 프레임의 드래그와 재정렬을 다듬고, 타이밍·재생·내보내기를 같은 흐름에서 확인했다.

03

화면을 옮길 때도 끊기지 않게.

트랙패드 팬의 방향과 지연을 확인하고, 입력을 모아 처리하는 방식과 렌더링 재사용 경로를 조정했다.

PREVIEW TO FILE

미리 본 결과를,
그대로 파일로.

정지 이미지와 GIF를 내보내기 전에 실제 인코딩 결과와 파일 크기를 확인한다. 저장할 때도 같은 바이트를 사용해, 미리보기와 전달 파일이 어긋나지 않도록 했다.
